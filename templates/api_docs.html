📋 API 文檔

BurnSky 燒天預測系統提供 RESTful API，讓開發者可以輕鬆整合燒天預測功能到自己的應用中。

基本資訊

  • Base URL: http://localhost:5001
  • API 版本: v1
  • 回應格式: JSON
  • 認證: 不需要
  • 速率限制: 200 請求/小時（預測類 100/小時）

🔥 核心 API 端點

GET 原評估與實況對照

GET /api/prediction/cross-check?assessment_id=...

先取得預測回應的 assessment_id，再讀取該次不可覆寫的原評估。此端點不重新計算日落分數。缺少或格式無效的 ID 回傳 400，找不到原評估回傳 404，服務失敗回傳 503。

comparison_state：pending（未到時段）、ended（已過時段而未保存影像）、out_of_window（原評估不在觀賞時段）、insufficient（原資料不足）、unmatched（影像未配對）、aligned_reference（同時段方向的影像更新參考）。

observations 只包含相符方向的攝影機；source_updated_at 是 HTTP Last-Modified，不是經核實的拍攝時間。captured_at 保持 null；retrieved_at 和 analyzed_at 分開列明。時間配對需在同一觀賞時段及評估時間前後15分鐘內，且圖片更新不超過15分鐘。

圖片上半部暖色像素比例並非燒天評分；光線不足時回傳 null。score_difference 及 accuracy 保持 null。此功能不會補造過去時段的影像。

分數與時間：burnsky_score 是 0–100 的燒天條件指數，並非發生機率。舊欄位 probability 保留為 null，請勿轉換成百分比機率。

資料限制：data_quality.status 目前為 limited；缺失因子回傳 null、不補分，總分上限維持150；input_coverage 列出可用因子及權重覆蓋率。ML暫未通過真實資料驗證，ml_score 為 null，實際權重為傳統100%、ML0%。部分可用因子仍屬間接推算，詳見 limitations。這不代表經校準的信心或準確率。缺少主要溫度、濕度或預報文字時，端點回傳 HTTP 503、error: insufficient_prediction_data 及 burnsky_score: null，並於 message 說明原因；不會計分或新增評分紀錄。

prediction_timing.generated_at 為指數計算時間，evaluated_at 為實際評估時間，均附香港時區偏移。當前條件的兩者相同；推算評估則相差指定小時數。快取回應保留原本計算時間。

prediction_timing.event_at 是評估當日的日出／日落參考時間；window_start、window_end 是前後 30 分鐘參考範圍，並非燒天持續時間。within_reference_window 表示評估時間是否在該範圍內。weather_updated_at 為原始天氣觀測更新時間，未提供時為 null。

GET 日落燒天預測

GET /predict/sunset?advance_hours=0

獲取日落時段的燒天預測資訊，包括評分、天氣因子和拍攝建議。

查詢參數

參數 類型 必需 說明
advance_hours integer 否 提前預測小時數 (0-48, 預設: 0)

GET 日出燒天預測

GET /predict/sunrise?advance_hours=0

獲取日出時段的燒天預測資訊。

POST ML 燒天預測

POST /api/ml-prediction

使用機器學習模型根據自定義天氣參數進行預測。

請求 Body (JSON)

{ "cloud_coverage": 50, "humidity": 70, "wind_speed": 15, "temperature": 20, "time_of_day": 18 }

📊 數據查詢 API

GET 天氣數據

GET /api/weather

獲取當前天氣數據，包括溫度、濕度、風速等。

GET 最佳拍攝地點

GET /api/locations

獲取香港推薦的燒天拍攝地點清單。

GET 日出日落時間

GET /api/astronomy

獲取當日的日出日落時間、黃金時段等天文數據。

📸 照片相關 API

GET 照片案例

GET /api/photo-cases

獲取燒天照片案例數據庫中的記錄。

POST 照片分析

POST /api/analyze-photo

上傳照片進行 AI 分析，獲得燒天品質評分。

Content-Type: multipart/form-data

參數: photo (file), rating (int 1-10)

⚠️ 警告台 API

GET 警告台數據

GET /api/warning-dashboard-data

獲取警告台儀表板所需的統計數據和歷史記錄。

使用範例

JavaScript (Fetch API)

// 獲取日落預測 async function getSunsetPrediction() { try { const response = await fetch('/predict/sunset?advance_hours=0'); const data = await response.json(); console.log('燒天評分:', data.score); console.log('建議:', data.recommendation); } catch (error) { console.error('API 錯誤:', error); } }

Python

import requests def get_sunset_prediction(): try: response = requests.get('http://localhost:5001/predict/sunset?advance_hours=0') data = response.json() return { 'score': data['score'], 'recommendation': data['recommendation'] } except requests.RequestException as e: print(f'API 錯誤: {e}') return None

curl

curl -X GET "http://localhost:5001/predict/sunset?advance_hours=0"

錯誤處理

API 使用標準 HTTP 狀態碼。錯誤回應格式：

{ "error": "錯誤類型", "message": "詳細錯誤信息" }
