# AdSense「缺乏價值的內容」檢查紀錄

檢查日期：2026-11-26。檢查對象：專案模板、索引及廣告設定，以及公開首頁 https://burnsky-api.onrender.com/ 。

## 判斷

網站已有燒天條件工具、天空實況、地點與攝影指南，不能僅從拒絕通知判定哪個頁面導致拒絕。Google 沒有在這則通知中指定違規頁面；本次修正處理可確認的內容與發布問題，不能證明整站已符合所有政策，也不能保證重新審查通過。

Google 要求獨創、實用內容、清楚導覽及真實提供所承諾的服務；單純增加文章數量、字數、SEO 標籤或修正 ads.txt 不能取代內容品質。參考：[AdSense 內容和使用者體驗](https://support.google.com/adsense/answer/10015918?hl=zh_TW)、[Google 發布商政策](https://support.google.com/adsense/answer/9335564?hl=zh_TW)。

## 已完成的修正

- [攝影指南](../templates/photography_guide.html)加入評估時間、太陽方向、現場曝光、失敗情境及回報方法，示範流程明確標示為示範，沒有捏造實拍案例。
- [拍攝地點](../templates/best_locations.html)加入視野與交通／安全取捨比較，移除青馬大橋「世界最長懸索橋」的說法，修正全年固定六點到場的建議。
- [運作原理](../templates/how_it_works.html)列出香港天文台與 MET Norway 來源、授權、資料時間及主觀驗證限制；[關於頁](../templates/about.html)說明獨立開源專案及更正管道。
- [FAQ](../templates/faq.html)移除沒有依據的 App／推送開發承諾與固定燒天持續時間；[聯絡頁](../templates/contact.html)移除固定回覆期限，提醒 GitHub 回報是公開的。
- [首頁](../templates/index.html)移除無法佐證的 LocalBusiness／專業精準預測資料，以及沒有對應可見問答的 FAQ 結構化資料；保留 WebApplication 等適用資料。
- [廣告設定](../modules/publishing.py)預設停用載入廣告，保留帳戶驗證 meta 及既有 ads.txt。`ADSENSE_ENABLED=true` 只允許指南、地點、術語、FAQ、運作原理五個內容頁載入廣告。首頁、工具、狀態、測試、聯絡及政策頁不載入廣告。原本缺少廣告單元 ID 的手動廣告區塊已移除。
- API、系統狀態、測試與錯誤回應提供 `X-Robots-Tag: noindex`；[網站地圖](../static/sitemap.xml)移除狀態頁與 robots.txt，加入預測紀錄，僅更新實際修改頁面的內容日期。noindex 不代表存取限制，也不等於通過 AdSense。
- 移除全站頁尾固定的「最後更新」日期，避免把網站設定日期誤當成每頁內容或天氣資料更新時間。

## 重新送審前仍需完成

1. 部署本次修正至實際送審網域，再以手機與桌面驗證導覽、預測、資料不足狀態、影像及上傳功能。此次檢查沒有發布變更或登入 AdSense。
2. 由維護者核實交通、開放時間、地點名稱和照片權利。地點內容目前是行程準備建議，不代表已實地勘察。
3. 持續公開有授權、可核對的實拍或預測對照：香港日期時間、拍攝地點與方向、留底預測、實際結果，以及成功／失敗原因。沒有可靠資料時不要寫成成功案例；不要只收集高分或成功樣本。
4. 確認主要工具在正式環境確實可用；查閱真實訪客使用紀錄與回報，修正空白、卡住或不實用的流程。此次沒有存取 Analytics 或 Search Console，不能證明使用者興趣或回訪程度。
5. 確認正式環境的專案／Issue 或電郵聯絡管道可用、私隱說明符合實際收集與保存資料的行為，並核對第三方資料及廣告的適用政策。完成後在 AdSense「網站」提出審查，是否通過由 Google 決定。
